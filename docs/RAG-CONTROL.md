# Контрольная сверка RAG

Проверены значения, подписи метрик и номера страниц. Для D004 проверена строка Entity Match (%) из таблицы 2 на странице 6. Для D020 проверены обе строки и все семь метрик таблицы 10 на странице 7. Реестр транскрипции хранится в `lib/rag-control-reference.json`. Приложение сверяет его с текущим научным снимком и выводит ссылки на страницы в «Проверки и метрики».

Выборка целевая. Её итог отдельно от результатов эталонного прогона по корпусу. Независимая оценка корпуса остаётся в исходном отчёте и требует пригодного независимого эталона.

## Воспроизводимые сравнения

В интерфейсе откройте «Сравнение», RAG и нажмите кнопку соответствующего контрольного примера. Либо запустите из корня проекта:

```powershell
$catalog = "data/rag/quality-run-2/handoff/catalog.json"
python tools/quality/compare_catalog.py $catalog D004/R001 D004/R002
python tools/quality/compare_catalog.py $catalog D020/R001 D020/R002
python tools/quality/compare_catalog.py $catalog D002/R001 D002/R002
```

Ожидаемые ответы. Для D004 `comparable` и 10,6 п.п. Для D020 `incompatible` из-за Recall@6 и Recall@3. Для D002 `insufficient_data` из-за шкалы, которую имеющиеся доказательства не подтверждают.

## Оригиналы NASA

После пересборки индекса космических публикаций выполните `node --env-file-if-exists=.env.local scripts/index-space-pdfs.mjs`. Команда скачивает PDF из каталога NASA NTRS, проверяет формат, индексирует извлечённый текст постранично и сохраняет контрольные суммы. Для источников с одной аннотацией интерфейс показывает аннотацию и ссылку на первоисточник.
