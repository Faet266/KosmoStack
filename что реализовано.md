# KosmoStack

Локальное научное рабочее пространство для поиска результатов в публикациях и проверки, откуда взято каждое число. Проект связывает PDF, страницу, метрику, значение и условия измерения. Подготовка к сравнению начинается со сверки источников и шкал.

Порядок установки и запуска описан в [README-START.md](README-START.md).

## Что реализовано

| Раздел | Возможности |
| --- | --- |
| Области исследований | Три встроенные области: тонкоплёночные солнечные элементы, RAG и поиск по документам, космос. Библиотека публикаций и каталог результатов открываются отдельно. |
| Личный кабинет | Создание и удаление личных областей, загрузка PDF перетаскиванием, закладки и переход к конкретному документу из чата. |
| Анализ PDF | Извлечение текста через PDF.js, OCR сканов через Tesseract.js с английским и русским языками, числовые кандидаты и теги, привязка к странице. |
| Публикации и теги | Поиск по публикациям, тегам и доступному тексту. Переход между совпадениями с подсветкой на странице PDF. Цитаты из файла и библиография с доступными метаданными. |
| Сравнение | Выбор записей A и B. Сверка метрики, k, шкалы и условий для RAG, сопоставление источников для солнечной и космической областей. При несовпадении условий или нехватке данных показывается причина. |
| Проверки и паспорт | Очередь проверки источников, контрольные примеры и отчёт качества подготовленного корпуса RAG. Паспорт выбранной области и сводный паспорт. |
| Экспорт | PDF, DOCX, ODT, CSV и XLSX для поддерживаемых отчётов. CSV хранит строки данных. XLSX добавляет оформление, листы и фильтры. |
| Ассистент | Локальная модель Ollama получает фрагменты из базы и данные анализа. Доступны чат, работа с личными областями и перевод. |
| Интерфейс | Светлая и тёмная темы, карточки выбора записей в сравнении, адаптация к узким экранам. |
| Хранение | PostgreSQL для документов, индексов и результатов. Локальная SQLite для профилей, кодов входа и сессий. |

## Как проходит работа

1. Создайте личную область и загрузите свой PDF.
2. После анализа найдите документ по названию или тегу.
3. Откройте найденную страницу и сверьте текст, метрику и значение с оригиналом.
4. Выгрузите анализ или паспорт области в нужном формате.

PDF можно загружать размером до 25 МБ. Качество OCR зависит от скана. Цифры, выделенные автоматически, требуют сверки с источником.

## Состав облегчённого архива

В архиве есть код сайта, SQL-миграции, конфигурация, эмблема, скрипты анализа и экспорта, вспомогательные инструменты качества и два README. Встроенные области отображаются в меню. Загруженные PDF, корпуса, результаты предобработки, локальные базы, учётные записи, секреты, зависимости и модель Ollama в архив не входят. Для демонстрации можно создать область и загрузить свои документы сразу после установки.
